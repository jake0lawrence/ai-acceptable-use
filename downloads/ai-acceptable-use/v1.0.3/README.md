# AI Acceptable-Use Policy, version 1.0.3

A plain-language AI acceptable-use policy for small governments and nonprofits: fifteen rules, each with a no-code way to follow it.

Published 2026-11-20. License: CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/). Canonical page: https://jakelawrence.xyz/research/ai-acceptable-use

> This is a starting template, not legal advice. Public-records and privacy laws differ by state, and procurement rules differ by funder too. Have counsel review it before you adopt it.

## Files

- `rules.json`
- `rules.csv`
- `questions.csv`
- `policy.md`
- `CITATION.cff`
- `README.md`
- `manifest.json`
- `SHA256SUMS`

`policy.md` is the full template (every rule, no questions answered out). `rules.csv` and `rules.json` hold the same rules as data, with the question answers that make each one apply.

Verify the files with `sha256sum -c SHA256SUMS`.
